# Bravewaffles Website

The marketing site for bravewaffles.io — home, the Consistent Notes product page, docs, terms, and privacy. Built with Astro and deployed to GitHub Pages.

## Language

**Consistent Notes**:
The canonical product name everywhere on this site and in its Docs. The app binary is historically "Consistency"; marketing never uses the old name.
_Avoid_: Consistency, Consistent Note

**entry**:
A single day's page in Consistent Notes, dated `YYYY-MM-DD` and exported as one `.md` file. The canonical term for a day's writing; "note" appears only in the product name and the export folder name.
_Avoid_: note (for a day's page), document, page

**Docs**:
The canonical name of the Consistent Notes user documentation section. Never "Manual", "Help", "FAQ", or "Support Library".
_Avoid_: manual, help center, knowledge base

**menu bar**:
The bar at the top of the Mac screen. The canonical Apple form, per the Apple Style Guide and Human Interface Guidelines.
_Avoid_: menubar, menu-bar
