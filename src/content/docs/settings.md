Open Settings with **⌘,** or from the gear menu. Four tabs: General, Shortcuts, Data, and Subscription.

## General

### Editor

| Setting | Default | What it does |
|---|---|---|
| Auto Save | on | Saves 1.5 s after you stop typing (and on close/navigate) |
| Roll Over Todos | off | Copies open todos from previous days into today's entry automatically |
| Spell Check | off | Underlines misspelled words and grammar issues as you type |
| Autocorrect | off | Needs spell check on |
| Markdown delimiters | Current line | When formatting characters show: Always show / Current line / Hidden |
| Hide formatting toolbar | off | Hides the toolbar (same as **⌘⇧T**) |

### Reminders

| Setting | Default | What it does |
|---|---|---|
| Enable daily reminder | off | Sends a daily notification at the time below. See [Reminders](/consistent-notes/docs/reminders/) |
| Reminder time | 9:00 AM | Only shown while the reminder is on |

### Startup

| Setting | Default | What it does |
|---|---|---|
| Launch at login | off | Starts Consistent Notes when you log in |

### Menu Bar

| Setting | Default | What it does |
|---|---|---|
| Pin icon to far right | on | Keeps the menu bar icon in the rightmost slot; still draggable with **⌘** and your spot is remembered |

### Themes

| Setting | Default | What it does |
|---|---|---|
| Theme | System Default | All 27 themes with a live preview. See [Themes](/consistent-notes/docs/themes/) |

### View

| Setting | Default | What it does |
|---|---|---|
| Hide tab bar | off | Removes the Notes / Heatmap / ToDos tabs; view switching stays on **⌘N / ⌘Y / ⌘T** |
| More vertical space | off | A taller popover, so more content fits |

### Vim Mode

| Setting | Default | What it does |
|---|---|---|
| Vim motions in tabs | off | **j/k**, **gg/G**, **o/O** in the Notes and ToDos lists |
| Vim mode in editor | off | Full modal editing in the editor |
| Move up and down by visual lines | on | **j/k** follow wrapped lines; counts like `5j` always use logical lines |
| Escape sequence | — | Two keys that exit Insert mode (classic: `jk`) |
| Show vim indicator | on | The **N / I / VISUAL** mode badge in the editor header |
| Hardcore mode | off | Disables arrow keys in the lists. See [Vim mode](/consistent-notes/docs/vim-mode/) |

## Shortcuts

The global shortcut recorder (**⇧⌘C** default) and the full shortcut reference for the current mode. See [Keyboard shortcuts](/consistent-notes/docs/keyboard-shortcuts/).

## Data

The notes folder (where Markdown exports go — see [Where your entries live](/consistent-notes/docs/where-your-notes-live/)), **Show in Finder**, and **Change…** to pick a new folder. Recovery's **Rescan** button imports dated `.md` files from the folder for days missing in the app and reports the tally as **Imported / Skipped / Errors**. Rescan never touches entries that already have content.

## Subscription

Your plan status: trial days remaining, plan, renewal date, and buttons to change plans, restore purchases, or manage the subscription in your App Store account.
